# Memory Collage

Lovable Prompt（完整版）

Build a modern interactive travel journaling web application called “Fragmented”.

Product Concept

Fragmented means “fragmented storytelling”.

The platform allows users to transform travel memories into artistic digital collages.

Unlike traditional timeline-based travel records, users can freely arrange photos, tickets, receipts, maps, locations, notes, stickers, and audio clips on an infinite canvas.

The goal is to create emotional visual stories rather than chronological records.
